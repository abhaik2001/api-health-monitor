🚦 API Health Monitoring System (DevOps Project)
📌 Project Overview

The API Health Monitoring System is a production-style DevOps monitoring application that continuously checks the health of external APIs and services.

It periodically probes configured endpoints, detects state changes (UP / DOWN), stores results persistently, and sends real-time notifications when failures occur.

This project demonstrates end-to-end DevOps practices, including:

Containerization

Cloud services integration

Infrastructure as Code (IaC)

Secure credential handling

Troubleshooting real-world deployment issues
